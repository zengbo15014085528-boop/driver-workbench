# 司机聚合工作台 🚕

> 网约车司机记账 & 订单辅助工具

给同时跑滴滴、T3、高德、曹操、哈啰等多个平台的司机用的工具。

**一句话介绍：订单汇总 + 智能排序 + 流水记账，帮司机少切 APP、多挣钱、算清账。**

## 解决什么问题

1. 来回切 APP 看单，太累还容易漏单
2. 分不清哪单值钱——60 元跑 30 公里 和 40 元跑 10 公里，哪个划算？
3. 收入散在几个平台，月底算糊涂账
4. 一个平台接了单，其他平台忘了关，容易撞单罚款

## 核心功能

- **订单看板**：订单截图一传，自动识别进看板。卡片显示平台、起终点、里程、预估金额、每公里单价。自动分三区：行程中置顶 → 🔥 单价最高的 3 单自动排最前 → 其余按自定义规则排。可设门槛自动隐藏低价单。
- **截图识别**：本地 AI（Tesseract.js，浏览器内离线运行）自动读出截图起终点、金额、里程，预填后让司机确认；识别不准的字段标黄提醒核对。首次使用需联网下载中文识别包，之后本地运行。
- **接单辅助**：点「已接单」弹窗安全提醒；一键拨打乘客电话、一键唤起高德/百度导航；行程结束填实收、高速费、停车费，自动算净收入入台账。
- **流水台账**：日/周/月流水、单均收入、净收入自动汇总，按日期分组，支持导出 CSV（Excel 可直接打开）。
- **自定义规则**：平台优先级拖拽排序、白天/夜间模式、高价单优先、夜间单提权、低价门槛隐藏。

## 安全底线（与抢单外挂的本质区别）

- ❌ 不自动操作任何网约车平台——不自动接单、不自动暂停出车
- ❌ 不用无障碍权限、不后台监听 APP
- ✅ 只做截图识别、人工录入、信息汇总、提醒和记账
- 🔒 数据只存在司机自己手机里（localStorage），**不上云**

对外统一口径：**网约车司机记账 & 订单辅助工具**

## 本地运行

```bash
npm install
npm run dev       # 开发模式 http://127.0.0.1:5173
npm run build     # 生产构建，输出到 dist/
npm run preview   # 预览构建产物 http://127.0.0.1:4173
```

手机浏览器打开即可使用。数据保存在浏览器 localStorage，清除浏览器数据会丢失，重要流水建议定期导出 CSV。

## 技术栈

React 18 + Vite 6 + Tesseract.js（本地 OCR）+ localStorage。纯前端、无后端、无数据上传。
